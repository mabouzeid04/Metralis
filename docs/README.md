# Documentation

## Overview

This directory contains all non-code documents that define the vision, strategy, architecture, research, and product direction for the Factory Intelligence Layer.

It is the complete AI-ingestible knowledge base for the company.

## Subfolders & Their Purpose

### /vision

Long-term worldview, mission, and the future of autonomous manufacturing.

### /product

Definitions of what we are building, why, for whom, and how it works.

### /architecture

Technical blueprints: data models, AI reasoning, ingestion pipelines, and system design.

### /strategy

Business strategy: markets, competition, pricing, GTM, differentiation.

### /pitch

Messaging and communication: pitch scripts, taglines, deck language, website copy.

### /execution

Operational and execution plans: MVP, milestones, risks, partnerships, pilots.

### /research

Domain knowledge about factories, maintenance, downtime, and workflows.

### /meta

Glossary, design principles, open questions, and idea scratchpads.
